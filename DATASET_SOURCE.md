# Group 4 — Diabetes Prediction Dataset Source

**Course:** ITAI 1371 — Introduction to Machine Learning  
**Project:** Midterm — Exploratory Data Analysis and Data Preprocessing

**Dataset Name:** Diabetes Prediction Dataset

**Source:** Kaggle

**Dataset URL:** https://www.kaggle.com/datasets/iammustafatz/diabetes-prediction-dataset

**Original Dataset Size:** 100,000 records and 9 columns

**Target Variable:** `diabetes`

**Project Description:**

Our group selected the Diabetes Prediction Dataset to prepare data for a machine learning classification project. The goal is to predict whether a patient has diabetes using demographic and health-related information.

Using Python, we reduced the dataset to 50,000 records through stratified random sampling, preserving the original diabetes class distribution. We then divided the sampled data into 70% training and 30% testing.

All exploratory analysis, feature engineering, scaling, and SMOTENC class balancing were performed on the training dataset. The testing dataset was kept separate for future model evaluation.
